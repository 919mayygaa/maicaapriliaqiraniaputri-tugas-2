# Portofolio Maica Aprilia Qirania Putri

Website portofolio pribadi yang saya buat sebagai bagian dari pembelajaran di Kelas Industri UBIG.

Saya adalah siswi kelas 10 PPLG 1 di SMK Brantas Karangkates yang sedang belajar membuat website dan mengembangkan keterampilan di bidang pemrograman.


## Fitur

- **Beranda:** Berisi perkenalan diri, hobi, cita-cita, dan keahlian.
- **Proyek:** Menampilkan proyek yang telah saya kerjakan selama pembelajaran.
- **Kontak:** Berisi informasi untuk menghubungi saya.
- **Desain responsif:** Tampilan website menyesuaikan ukuran layar perangkat, jika sudah diterapkan pada project.

## Teknologi yang Digunakan

- HTML5 untuk menyusun struktur halaman website.
- CSS3 untuk mengatur tampilan dan desain website.
- JavaScript untuk menambahkan interaksi, jika digunakan.
- Git untuk mencatat perubahan project.
- GitHub untuk menyimpan repository secara online.
- Vercel untuk mempublikasikan website.

## Tujuan Pembuatan

Project ini dibuat untuk melatih kemampuan saya dalam membuat website, memahami penggunaan Git dan GitHub, serta mempelajari cara mempublikasikan website menggunakan Vercel.
